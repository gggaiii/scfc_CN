# SCFC 中文官网

一个面向中文球迷的斯托克波特郡足球俱乐部首页原型，包含球队介绍、自动赛程、中文阵容、历史、新闻和球迷商店模块。

## 本地运行

安装依赖：

```powershell
npm install
```

启动开发服务器：

```powershell
npm run dev
```

构建生产版本：

```powershell
npm run build
```
