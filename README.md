# SCFC 中文官网

一个面向中文球迷的足球俱乐部官网首页原型，包含新闻、赛程、票务、俱乐部介绍和青训社区模块。

## 本地运行

安装依赖：

```powershell
npm install
```

启动开发服务器：

```powershell
npm run dev
```

构建生产版本：

```powershell
npm run build
```
